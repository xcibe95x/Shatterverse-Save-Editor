# Observed stone records

This bundled catalog contains 61 unique observed trinket records, including observations dumped read-only from the user's current save. It retains each observed ID, set, level/rank, serialized roll values, unknown flag, and secondary-stat map. Per-save `ServerId` values are omitted because they identify individual owned instances rather than catalog entries.

The file intentionally keeps repeated IDs and their differing observations. The Workshop can add further observations from another `.sav` file or an exported `.trinket`; these additions persist locally in the app's WebView storage. Values are examples seen in saves, not verified ranges or canonical game definitions. Do not infer valid roll caps from this dataset alone.
